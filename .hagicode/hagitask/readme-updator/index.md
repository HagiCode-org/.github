# README requirements

## Audience and focus

- Address maintainers of the organization-level `.github` repository. The current `README.md` is a one-line title; the organization profile content lives in `profile/README.md` with its own translations and is outside this README set.

## Required content

- Keep the README short: name the repository, say that it holds the organization profile, and point to `profile/`.
- Describe only files that exist in the repository.

## Exclusions

- Exclude tokens, secret values, internal hosts, machine-specific paths and private links.
