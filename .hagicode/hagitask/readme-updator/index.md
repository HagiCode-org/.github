# README requirements

## Product focus

- Present this repository as the home of the HagiCode GitHub organization profile, the public introduction that visitors see on the organization page, which describes HagiCode as an AI workbench for project development.
- Address visitors to the HagiCode organization on GitHub. The current `README.md` is a one-line title; the profile content lives in `profile/README.md` with its own translations and is outside this README set.
- Lead with what the profile gives visitors and where to find it.

## Required content

- Keep the README short: name the repository, say that it holds the organization profile, and point to `profile/`.
- Describe only files that exist in the repository.

## Exclusions

- Exclude tokens, secret values, internal hosts, machine-specific paths and private links.
- Keep repository maintenance instructions out of the README: repository layout, internal architecture, CI and contribution workflow.
- Do not list features the profile does not show.
