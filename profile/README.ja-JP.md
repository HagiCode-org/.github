## HagiCode を選ぶ理由

- **提案駆動の AI コーディング**：`OpenSpec` がスコープ、タスク、影響分析、検証、実行をつなぎ、複雑な作業を場当たり的な編集にしません。
- **柔軟な Agent とモデルのルーティング**：主要な Agent CLI と `OmniRoute` により、対話レイヤーとモデルレイヤーを分けて選択できます。
- **完全な開発ワークスペース**：`MonoSpecs`、`Skills`、`Vault`、`AI Compose Commit`、`code-server` が、複数リポジトリ作業、知識蓄積、仕上げの手順を 1 つの環境にまとめます。
- **実際のシグナルに基づくゲーム化フィードバック**：実績、デイリーレポート、効率倍率、token throughput により、長時間の AI 作業を把握しやすくします。
