## 为什么选择 HagiCode

- **提案驱动的 AI 编码**：`OpenSpec` 将范围、任务、影响分析、验证与执行保持在同一链路中，而不是让复杂工作退化成盲改。
- **灵活的 Agent 与模型路由**：主流 Agent CLI 与 `OmniRoute` 让团队能够分别选择交互层与模型层。
- **完整的开发工作区**：`MonoSpecs`、`Skills`、`Vault`、`AI Compose Commit` 与 `code-server` 把多仓协作、知识沉淀与收尾步骤都放进同一个系统。
- **带有真实信号的游戏化反馈**：成就、日报、效率倍率与 token 吞吐量让长期 AI 协作更容易阅读和管理。
